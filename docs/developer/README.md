- [Hooks and filters](hooks-and-filters.md): what other plugins and themes can hook into.
- [Testing](testing.md): linting, the browser and admin test suites, and how to run them.
- [Releases and updates](releases-and-updates.md): semantic branch names, Conventional Commit titles, release-please, the release zip, and the auto-updater.
- [Design spec](design-spec.md): the original product spec and its decisions table.
